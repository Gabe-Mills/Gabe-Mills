I work at [Massed Compute](https://massedcompute.com) on GPU cloud: launch recipes, marketplace, design, public model writeups, and [Massed Minute](https://www.youtube.com/@MassedCompute) on YouTube. On my own time I ship native Apple apps, useful web tools, and stuff that comes off a 3D printer. I like the whole path — **the system underneath and the experience in your hands.**
